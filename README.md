 Chocolate Café

Protótipo de aplicativo de cardápio digital para cafeteria, focado em uma experiência simples, intuitiva e visualmente atrativa.

📱 Funcionalidades
Navegação por categorias
Busca de produtos
Visualização de detalhes
Seleção de tamanhos
Adição ao carrinho
Fluxo de finalização de pedido

🎨 Design e UX

Projeto desenvolvido no Figma, com foco em:
Interface moderna e organizada
Hierarquia visual clara
Experiência do usuário (UX)

💻 Tecnologias e conceitos
Figma (UI/UX e prototipação)
Conceitos de Front-end
Estruturação de interfaces
Lógica de navegação entre telas
Organização de componentes

💡 Objetivo
Projeto acadêmico voltado para prática de UX/UI Design aliado a conceitos de desenvolvimento front-end.
